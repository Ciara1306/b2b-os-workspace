# B2B OS - Customer-First Workspace

Website quản lý không gian làm việc B2B khách hàng ưu tiên (Customer-First Workspace), được tạo từ thiết kế Google Stitch.

## Tính năng chính
- **Responsive Đa nền tảng**: Tự động chuyển đổi giữa giao diện Desktop (Sidebar Navigation) và Mobile (App Tabbar).
- **Customer Context Management**: Quản lý thông tin khách hàng đang làm việc (SAINTTHAI Commercial).
- **Bộ tác vụ linh hoạt**: Lựa chọn nhanh Báo giá, Proposal, Hợp đồng hoặc sử dụng công cụ Doanh nghiệp (Nghiên cứu thị trường, Nội dung tăng trưởng).
- **AI Prompt Execution**: Tích hợp ô nhập lệnh ngôn ngữ tự nhiên và hiệu ứng xử lý AI tương tác thời gian thực.
- **Hộp thoại Modal & Toast Thông báo**: Xem lịch sử giao dịch khách hàng, chọn khách hàng từ danh bạ, và thông báo trạng thái.
- **Phím tắt**: Nhấn `⌘K` hoặc `Ctrl + K` để tìm kiếm nhanh.

## Triển khai trên Cloudflare Pages
1. Kết nối với GitHub repository này trên Cloudflare Dashboard (`dash.cloudflare.com`).
2. Build Settings:
   - **Framework Preset**: None (Static HTML)
   - **Build Command**: Để trống
   - **Build Output Directory**: `/`
3. Nhấn **Save and Deploy**.
